# blockr
A browser-based puzzle game where players strategically place blocks to fill the grid in as quick a time as possible.

## Play
https://playblockr.com

## Features
- Daily puzzle
- Statistics tracking
- Sharing results
- Responsive design for desktop and mobile
- Local save data
